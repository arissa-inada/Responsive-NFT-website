## Responsive NFT Website

Projeto simples e moderno simulando um site de NFTs shopping e com uso de crypto moedas. 

## Site publicado

https://arissa-inada.github.io/Responsive-NFT-website/

## Sobre o projeto

Este projeto foi criado para praticar:

Estruturação de layout com HTML

Estilização com CSS responsivo

Design visual atraente

Técnicas de layout moderno (flexbox / grid)

Publicação com GitHub Pages

A aplicação é um site responsivo apresentando NFTs e se adapta a diferentes tamanhos de tela.

🛠 Tecnologias usadas

HTML5

CSS3
